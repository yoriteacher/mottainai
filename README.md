# 못타이나이 9차시 · 학생용 웹앱

그림책 『もったいない』로 배우는 고등학교 일본어 회화 9차시 프로젝트의
학생용 발음 연습 화면입니다.

**바로 열기 → https://yoriteacher.github.io/mottainai/**

브라우저에 들어 있는 기능만 써서 만들었습니다. 설치할 것도, 요금도 없습니다.
# 1차시 발음 연습 웹앱 — 시제품

`1차시_발음연습.html` 파일 하나가 전부입니다. 외부 라이브러리를 쓰지 않아
인터넷이 느려도 화면은 바로 뜹니다.

---

## 학생이 하는 일

1. 반·번호·이름을 적습니다
2. 문장마다 **듣기**(또는 **천천히**)를 눌러 소리를 듣습니다
3. **말하기**를 누르고 따라 말합니다 → 점수와 「이렇게 들렸어요」가 바로 나옵니다
4. 맨 아래에서 여섯 문장을 이어 읽어 **30초 녹음**을 합니다
5. **선생님께 보내기**를 누릅니다 (점수와 녹음이 함께 갑니다)

**3번은 크롬 계열에서만 되고, 4번은 아이폰을 포함한 모든 기기에서 됩니다.**
그래서 제출의 중심은 **4번 녹음**입니다. 3번은 스스로 연습하는 도구로 보시면 됩니다.

## 무엇으로 채점하나

브라우저에 들어 있는 음성 인식(Web Speech API)으로 학생 말을 일본어 글자로 바꾼 뒤,
정답 문장과 얼마나 닮았는지 견줍니다. 설치할 것도, 요금도 없습니다.

- 음성 인식이 **한자로 알아들어도**(`勿体ない`) 정답으로 봅니다
- **촉음 っ** 이나 **장음 のう** 를 빠뜨리면 점수와 별개로 그 자리를 짚어 줍니다
- 점수보다 **「이렇게 들렸어요」**를 학생이 눈으로 견주는 것이 더 중요합니다

---

## ★ 선생님께 — 기록이 쌓이게 하려면

**기본 상태로는 학생 화면에서 끝납니다.** 아래 세 단계를 한 번만 해 두면
학생이 「선생님께 보내기」를 누를 때마다 선생님 시트에 자동으로 쌓입니다.

### 1. 스크립트 붙여 넣기
`..\대시보드\설치용_스크립트.gs` 를 엽니다. 이미 응답 시트를 만드셨다면
그 스프레드시트에서 **확장 프로그램 → Apps Script** 를 열고 파일 전체를 붙여 넣으세요.

### 2. 웹 앱으로 배포
Apps Script 화면에서 **배포 → 새 배포 → 유형 [웹 앱]**

| 항목 | 고를 값 |
|---|---|
| 실행 사용자 | 나 |
| 액세스 권한 | **모든 사용자** |

배포를 누르면 `.../exec` 로 끝나는 주소가 나옵니다. 이 주소를 복사하세요.
(학생이 구글 로그인을 하지 않아도 되도록 「모든 사용자」여야 합니다.)

### 3. 학생 화면에 주소 넣기
학생 화면 위쪽 **「선생님만 — 기록 주소 넣기」**를 펼쳐 주소를 넣고 저장합니다.
그 기기에는 저장되므로 다음부터는 넣지 않아도 됩니다.

> 학생 기기마다 한 번씩 넣어야 합니다. 학교 크롬북처럼 여러 명이 쓰는 기기라면,
> 주소를 넣어 둔 뒤 **즐겨찾기**로 만들어 두시는 편이 편합니다.

### 어디에 쌓이나
응답 스프레드시트에 **「발음」 시트**가 새로 생기고 이렇게 기록됩니다.

| 타임스탬프 | 반 | 번호 | 이름 | 차시 | 1번문장 … 6번문장 | 평균 | 녹음 | 들린 말 |
|---|---|---|---|---|---|---|---|---|

- **녹음** 칸에는 드라이브 링크가 들어갑니다. 눌러서 바로 들으실 수 있습니다
  (파일은 내 드라이브의 **「못타이나이 녹음」** 폴더에 `1차시_3반_7_김하윤_0902_1042.m4a` 처럼 쌓입니다)
- **들린 말** 에는 학생이 실제로 뭐라고 말했는지가 그대로 남습니다.
  점수만 보는 것보다 발음 지도에 훨씬 쓸모가 있습니다

## 웹에 올려야 하는 이유

**마이크는 `https` 주소에서만 켜집니다.** 파일을 두 번 눌러 여는 방식
(`file://`)으로는 듣기만 되고 말하기·녹음이 되지 않습니다.

가장 간단한 방법은 **GitHub Pages**(무료·https)에 올리는 것입니다.
학교 홈페이지나 클래스룸에 올릴 수 있으면 그것도 좋습니다.

## 기기별로 되는 것

| | 듣기 | 30초 녹음 | 말하기 자동 채점 |
|---|---|---|---|
| 크롬 · 엣지 (PC·안드로이드·크롬북) | ○ | ○ | ○ |
| **사파리·크롬 (아이폰·아이패드)** | ○ | **○** | ✕ |

### 아이폰을 쓰는 학생은
**똑같이 참여합니다.** 아이폰은 음성 인식만 막혀 있고 녹음은 됩니다.

- 말하기 버튼은 흐리게 꺼져 있고, 대신 **녹음 버튼이 진하게** 보입니다
- 상단 안내도 「이 기기는 자동 채점이 되지 않지만 30초 녹음은 됩니다」로 바뀝니다
- 녹음을 내면 선생님 시트에 링크가 그대로 남습니다

즉 **제출물은 모든 학생이 같습니다.** 크롬을 쓰는 학생은 연습 중에
점수를 즉시 볼 수 있다는 점만 다릅니다. 평가는 녹음으로 하시면 공정합니다.

아이폰에서는 `audio/mp4`(.m4a), 크롬에서는 `audio/webm`으로 저장되며
두 형식 모두 드라이브에서 바로 재생됩니다.

## 다음 차시로 넓히려면

`SENT` 배열의 문장만 바꾸면 그대로 다른 차시 화면이 됩니다.

```js
var SENT = [
  { jp:"もったいない。", yomi:"못타이나이", ko:"아깝다",
    tip:"작은 っ 에서 한 박자 쉬어요",
    check:[["っ","작은 っ 에서 한 박자 쉬었나요?"]],
    alt:["もったいない","勿体ない"] },   // ← 음성 인식이 한자로 줄 때를 대비한 목록
  …
];
```

- `alt` 에는 **같은 말의 다른 표기**를 넣습니다. 많을수록 채점이 너그러워집니다
- `check` 는 **꼭 짚고 싶은 소리**입니다. 없으면 비워 두세요
- 보낼 때 `lesson: 1` 을 그 차시 번호로 바꾸면 시트에서 구분됩니다

8차시(2차 녹음)는 이 파일을 그대로 복사해 쓰시면
1차시 점수와 나란히 놓고 성장을 보실 수 있습니다.
