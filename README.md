# 못타이나이 9차시 · 학생용 웹앱

그림책 『もったいない』로 배우는 고등학교 일본어 회화 9차시 프로젝트의 학생 화면입니다.

**바로 열기 → https://yoriteacher.github.io/mottainai/**

브라우저에 들어 있는 기능만 써서 만들었습니다. 설치할 것도, 요금도 없습니다.

---

## 화면 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | **홈베이스** — 이름 고르기, 아홉 차시 목록, 나의 성장, 선생님 말씀 |
| `lesson.html?n=1`…`?n=9` | **차시 화면** — 아홉 차시가 이 파일 하나를 함께 씁니다 |
| `data.js` | **아홉 차시의 내용** — 고칠 것은 거의 여기뿐입니다 |
| `roster.js` | 학생 명단 (출석부 201·207·208반에서 뽑음) |
| `core.js` | 소리 내기 · 발음 채점 · 녹음 · 서버 주고받기 |
| `style.css` | 색과 글꼴 |

차시마다 화면을 따로 만들지 않았습니다. `data.js`에 적힌 **블록**을 엔진이 읽어 그립니다.

## 학생이 하는 일

1. 홈에서 **우리 반 → 내 이름**을 누릅니다 (한 번만. 그 기기에 저장됩니다)
2. 오늘 차시 카드를 누릅니다
3. 활동을 합니다 — 듣기·말하기·문장 만들기·녹음·쓰기
4. 맨 아래 **선생님께 보내기**
5. 다음 시간에 홈에 들어오면 **선생님 말씀**이 떠 있습니다 ← 환류

## 블록 여섯 가지

`data.js`의 `blocks` 에 넣는 것들입니다.

| type | 화면 | 쓰는 곳 |
|---|---|---|
| `sentences` | 문장 듣기 · 따라 말하기 · 점수 | 1·3·4·8·9차시 |
| `words` | 낱말 카드 (눌러서 듣기) | 2·5·6·7·9차시 |
| `builder` | **낱말 + 틀 → 내 문장** | 2·3·5·6·7차시 |
| `record` | 30초 녹음 | 1·8차시 |
| `rows` | 표에 적기 | 4·5·9차시 |
| `write` | 자유롭게 적기 | 거의 모든 차시 |

`builder` 가 이 수업의 핵심입니다. 새 문장을 짓게 하지 않고
**1차시의 여섯 문장을 틀로 쓰고 낱말만 갈아 끼웁니다.**
조사(을/를, 은/는)는 저절로 맞춰집니다.

## 무엇으로 채점하나

브라우저 음성 인식(Web Speech API)이 학생 말을 일본어 글자로 바꾸고,
정답과 얼마나 닮았는지 견줍니다.

- 한자로 알아들어도(`勿体ない`) 정답으로 봅니다 — `alt` 목록 덕분입니다
- **촉음 っ**, **장음 のう** 를 빠뜨리면 점수와 별개로 그 자리를 짚어 줍니다
- 점수보다 **「이렇게 들렸어요」**를 눈으로 견주는 것이 더 중요합니다

## 기기별로 되는 것

| | 듣기 | 30초 녹음 | 말하기 자동 채점 |
|---|---|---|---|
| 크롬 · 엣지 (PC·안드로이드·크롬북) | ○ | ○ | ○ |
| **사파리·크롬 (아이폰·아이패드)** | ○ | **○** | ✕ |

아이폰 학생도 **똑같이 참여합니다.** 말하기 버튼만 꺼지고 나머지는 모두 됩니다.
**평가는 녹음과 제출물로 하시면 공정합니다.**

## ★ 선생님께

### 한 번만 하는 준비

1. `..\대시보드\설치용_스크립트2_학생웹앱.gs` 를 Apps Script에 **통째로** 붙여 넣습니다
2. **배포 → 배포 관리 → 편집(연필) → 버전 [새 버전] → 배포**
   (주소는 그대로라 학생 화면은 고칠 것이 없습니다)
3. 시트 메뉴 **「못타이나이 → 성장표 새로 만들기」** 를 한 번 눌러 봅니다

### 시트에 쌓이는 것

**「기록」 시트** — 학생이 낼 때마다 한 줄. 같은 학생이 같은 차시를 다시 내면 **덮어씁니다.**

| 타임스탬프 | 반 | 번호 | 이름 | 차시 | 점수 | 제출물 | 녹음 | **선생님 말씀** | 학생이 읽음 |
|---|---|---|---|---|---|---|---|---|---|

- **반**은 수업 분반(201·207·208), **번호**는 원래 반-번호(`3-2`)입니다
- **선생님 말씀** 칸에 한 줄 적어 두시면 → 학생이 다음에 홈을 열 때 그 화면에 뜹니다
- 학생이 읽으면 **「학생이 읽음」** 칸에 시각이 자동으로 남습니다

**「성장표」 시트** — 과정중심평가용. 메뉴에서 새로 만들면 다시 그립니다.

| 반 | 번호 | 이름 | 1~9차시 | 낸 차시 | 만든 문장 수 | 발음 1차 | 발음 2차 | 늘어난 점 | 내가 준 말씀 |
|---|---|---|---|---|---|---|---|---|---|

- **아직 내지 않은 학생도 한 줄씩 나옵니다.** 그게 평가에 필요한 정보입니다
- 낸 차시가 3개 이하면 붉게, 발음이 오른 학생은 초록으로 표시됩니다
- `♪` 는 녹음이 들어 있다는 뜻입니다

### 학생이 바뀌면

`roster.js` 와 `.gs` 안의 `명단` 두 곳을 고칩니다. 출석부 xlsx에서 뽑은 값입니다.

### 내용을 고치려면

`data.js` 만 고칩니다. 화면 코드는 건드릴 일이 없습니다.

```js
{ type:"builder", title:"내 문장 카드 만들기",
  words:[W("ごはん","고항","밥"), W("みず","미즈","물")],
  frames:["taisetsu","sutenaide"] }        // 1차시 여섯 문장에서 가져온 틀
```

`alt` 에는 **같은 말의 다른 표기**를 넣습니다. 많을수록 채점이 너그러워집니다.
